# 🛡️ OpenShield AI

## Defensive Cybersecurity Analysis Platform

OpenShield AI is a defensive cybersecurity analysis platform designed to identify common web and network security issues and generate structured security reports.

The project focuses on authorized security testing, security visibility, risk analysis, and reporting.

---

## ✨ Features

### 🌐 Web Security Analysis
- HTTPS detection
- Security header analysis
- Cookie security checks
- URL validation
- Web risk assessment
### 📡 Network Security Analysis

- DNS analysis
- Port analysis
- TLS certificate analysis
- Network security indicators

### 🧠 Intelligence Layer

- Smart risk scoring
- Severity-based analysis
- Finding correlation
- Evidence generation
- Security recommendations

### 📊 Reporting System

- JSON reports
- HTML reports
- PDF reports
- Report verification
- Report search
- ZIP export

### 🤖 Telegram Security Bot

Available commands:

/start
/help
/about
/security
/analyze https://example.com
/network example.com
/reports
/reportinfo
/reportstats
/search keyword
